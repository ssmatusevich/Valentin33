# Валентинка: интерактивная страница

Веселая интерактивная страница ко Дню святого Валентина: кнопка `Да` растет после каждого нажатия `Нет`, появляются милые GIF, сердечки и музыка.

## Что внутри

- Главная страница с вопросом и двумя кнопками
- Кнопка `Нет` меняет текст, а затем начинает "убегать"
- Кнопка `Да` становится больше после каждого отказа
- Отдельная праздничная страница после ответа `Да`
- Фоновая музыка и кнопка включения/выключения звука

## Как запустить

1. Склонируйте репозиторий:
   `git clone https://github.com/ssmatusevich/Valentin.git`
2. Откройте папку проекта.
3. Запустите `index.html` в браузере.

## Структура проекта

```text
v-day/
├── index.html      # Главная страница
├── yes.html        # Страница после ответа "Да"
├── script.js       # Логика главной страницы
├── yes-script.js   # Конфетти и поведение страницы "Да"
├── style.css       # Стили и анимации
└── music/          # Музыка
```

## Настройка под себя

- Измените тексты в `index.html` и `yes.html`
- Замените сообщения и поведение кнопок в `script.js`
- Подправьте анимации и цвета в `style.css`
- Поменяйте трек в папке `music/`
